# Helfer entwickeln

Der aktuelle Vertrag, die Shell-API, Kontextregeln, Speicherung, Offline-Integration
und die kurze Checkliste stehen im
[Helper Authoring Guide](../../docs/HELPER_AUTHORING.md).

[`pain`](pain/README.md) ist die Referenz für Ereignisse, ortsbezogene Historie,
Guidance und Retention. Kleine Utility-Helper brauchen diesen Umfang nicht.
[Rabatt](discount/README.md) zeigt Berechnung und Ort,
[Trinken](drink/README.md) Ereignisse und Intervall.
